DR1FT — 1.0.0-prealpha.20
Summit conducible / nieve dinámica / suspensión y salida en subida

PARA JUGAR LOCALMENTE
1. Conserva todos los archivos y carpetas del proyecto.
2. En Windows abre INICIAR_WINDOWS.bat. Requiere Node.js 22 o posterior.
3. Mantén abierta la ventana del iniciador. El juego abre en http://127.0.0.1:8787
   Alternativa: ejecuta npm run preview dentro de esta carpeta.
4. Menú principal → SUMMIT · CONDUCIR → elegir auto → a la pista.

SUMMIT
El paisaje y sus texturas usan el modelo recibido. El trazado de 10,30 km,
los contactos y las carreras usan la simulación nativa de DR1FT.
La carrocería sigue las alturas negativas del modelo sin separarse de las
ruedas. La salida animada también toma la altura de la posición mostrada.
Los cinco autos pueden arrancar en la pendiente máxima de la ruta.

NIEVE
Reposo, avance, crucero, alta velocidad, aceleración, frenada, derrape y
reversa, con transiciones suaves. Los copos están en el mundo; al acelerar
se alargan y cambian de dirección con el movimiento de la cámara.

PRUEBAS
npm ci
npm run test:core
npm run test:summit
node scripts/validate-summit.cjs
